AI Security Guide

보훈심사위원회 실무자를 위한 생성형 AI 보안 가이드라인

타부처 공동 제작 v1.0 — 2026.05
기후에너지환경부 이미정 사무관과 AI 보안 표준화를, 한전 KDN 이창열 보안사업단장의 기술 자문을 받아 공동 제작한 가이드라인입니다. 공공기관 실무자가 생성형 AI를 안전하게 활용할 수 있도록 실질적인 기준을 제시합니다.
금지 — 절대 입력 금지
개인정보 · 보안 데이터
주민등록번호, 군번, 인사정보, 내부 시스템 접속 정보 등 법적 보호 대상 데이터는 어떤 AI에도 입력 불가
주의 — 비식별화 후 사용
업무 관련 민감정보
심사 대상자명, 사건번호, 구체적 질병명 등은 반드시 가명·일반화 처리 후 AI에 입력
허용 — 자유롭게 활용
일반 업무 · 공개 정보
법령 해석, 문서 양식 작성, 일반 행정 용어 정리, 회의록 요약(비식별) 등 공개 가능한 정보

1. 입력 데이터 보안

4 rules
1
필수
개인식별정보 입력 금지
이름, 주민등록번호, 전화번호, 주소 등 개인을 특정할 수 있는 정보는 절대 AI에 입력하지 않습니다.
비식별화 예시
"홍길동(780101-1xxxxxx)의 요건심의 건"
→ "신청인 A의 요건심의 건"
2
필수
내부 시스템 정보 입력 금지
보훈 업무 시스템 URL, 로그인 정보, 내부 서버 주소, API 키 등 시스템 접속 정보는 절대 입력하지 않습니다.
3
권장
사건번호·질병명 가명 처리
구체적 사건번호, 질병명, 부대명 등은 일반화하거나 가명으로 변환한 뒤 입력합니다.
비식별화 예시
"2026-심사-0142 건의 PTSD 진단 관련"
→ "최근 심사 건의 정신건강 관련 진단"
4
권장
대화 기록 관리
AI 대화 내용은 업무 종료 후 정리합니다. 민감 정보가 포함된 대화는 삭제하고, 유용한 프롬프트만 별도 보관합니다.

2. AI 도구 사용 원칙

4 rules
5
필수
AI 결과물 반드시 검증
AI가 생성한 내용은 반드시 실무자가 사실관계를 확인합니다. AI는 보조 도구이며, 최종 판단은 항상 사람이 합니다.
6
필수
허가된 AI 도구만 사용
기관에서 승인한 AI 서비스만 업무에 사용합니다. 출처가 불분명하거나 검증되지 않은 AI 도구는 사용하지 않습니다.
7
참고
프롬프트에 역할 부여
AI에게 "보훈심사 전문가" 등 역할을 부여하면 더 정확한 답변을 얻을 수 있습니다. 단, 역할 설정에 실제 기밀 정보를 포함하지 마세요.
프롬프트 예시
"당신은 공공기관의 행정심사 전문가입니다. 다음 심사 요건에 대해 법적 근거를 정리해 주세요."
8
참고
AI 활용 사실 기록
업무에 AI를 활용한 경우, 케이스 측정 템플릿에 기록합니다. 어떤 업무에, 어떤 도구를, 어떻게 사용했는지 남기면 팀 전체의 노하우가 됩니다.

3. 한눈에 보는 Do / Don't

DO — 이렇게 하세요

  • 법령·판례 해석 요청 시 일반화된 표현 사용
  • 문서 초안 작성 후 반드시 사실관계 검증
  • 프롬프트 템플릿을 팀과 공유
  • AI 활용 결과를 케이스 측정 템플릿에 기록
  • 비식별화된 데이터로 업무 효율화
  • 유용한 프롬프트를 별도 문서로 관리

DON'T — 이것만은 하지 마세요

  • 개인정보(이름, 주민번호 등)를 AI에 입력
  • 내부 시스템 접속 정보를 AI에 노출
  • AI 결과물을 검증 없이 그대로 사용
  • 비인가된 AI 도구로 업무 처리
  • AI에 기밀 등급 문서 내용을 입력
  • AI 결과물을 공식 문서로 바로 제출

4. AI 사용 전 체크리스트

매번 AI를 사용하기 전에 확인하세요
✓
입력하려는 내용에 개인식별정보(이름, 주민번호, 전화번호)가 포함되어 있지 않은가?
✓
입력 내용에 내부 시스템 정보(URL, 비밀번호, 서버 주소)가 포함되어 있지 않은가?
✓
사건번호, 질병명, 부대명 등이 가명 또는 일반화 처리되었는가?
✓
사용하려는 AI 도구가 기관 승인된 서비스인가?
✓
AI 결과물을 사실관계 검증 후 활용할 계획인가?
✓
활용 내용을 케이스 측정 템플릿에 기록할 준비가 되었는가?
